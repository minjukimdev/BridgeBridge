# BridgeBridge

A simple BridgeBridge Controller for Real time analytics and monitoring.

With BridgeBridge, you get a lightweight tool that stays out of your way.

**What you get**

- A simple BridgeBridge Controller for
- Real time analytics and monitoring

## Key Features

- A simple BridgeBridge Controller for
- Real time analytics and monitoring

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/BridgeBridge.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

BridgeBridge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
